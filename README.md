# bheguesta-Kali-Server-Configs

## Configuração de servidores no Kali Linux, montagem de redes simuladas e criação de um site 

Este repositório armazena arquivos de configuração essenciais utilizados na configuração, gerenciamento e reforço de segurança (hardening) de servidores rodando Kali Linux,  Montagem e configuração de rede(s) em ambientes simulados.

---

## Estrutura do Repositório

O repositório está organizado com os seguintes arquivos e diretórios de configuração:

*sshd_config* — Configurações do servidor OpenSSH, focadas em acesso remoto e segurança.

*dhcpd.conf* — Configurações para o servidor DHCP da rede local( Isolada na VM).

*authorized_keys* — Exemplo de arquivo de chaves públicas autorizadas para autenticação SSH (as chaves reais foram substituídas por motivos de segurança pessoal).

*interfaces* — Configurações de rede das interfaces de rede.

*ConexaoWirelessCabo* — Montagem de rede(s) simulada(s) na app Cisco Packet Tracer.

*Guilg* — Contém os arquivos ".html" e ".css", que foi dado como uma atividade  escolar.



---

##  Nota de Segurança
Todos os dados sensíveis, endereços IP reais e chaves SSH privadas ou publicas nestes arquivos foram anonimizados ou substituídos por valores fictícios para fins de demonstração pública.
